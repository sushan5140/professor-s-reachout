I’ve been working on a physiological ML project where the overall model initially looked reliable, but when I checked people separately, one subject performed much worse than the population result suggested. That led me to work on subject-conditional calibration.

It made me curious about what happens when we add more modalities.

A multimodal system can improve the average result because one signal helps another, but I wonder whether it can also make certain failures harder to notice. For example, if one physiological signal becomes unreliable for a particular person, the model may still give a confident answer because the other modality is carrying it.

A small experiment I’d like to try is to compare the same model with all modalities present, one modality weakened or removed, and different subjects held out. I’d then look at whether the model’s confidence and explanations actually reflect which signal it is relying on, or whether the final prediction stays confident even when the useful evidence has changed.
