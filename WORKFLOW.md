# Outreach Workflow

This repository is the persistent source of truth for professor outreach.

## For every professor

1. Research current lab/profile and recent work.
2. Create or update `professors/<university>/<professor>.md`.
3. Record:
   - professor name
   - university / department
   - lab
   - email
   - research fit / recent-work hook
   - exact outgoing email subject + body
   - proposal title/path if any
   - status
   - sent date
   - reply summary
   - next action
4. Update `TRACKER.md`.
5. After sending, change status from `DRAFTED` / `READY_TO_SEND` to `SENT`.
6. If a reply arrives, summarize it in the professor file and update the tracker.

## Privacy rule

The repository is public. Store our outgoing email text in full. For incoming professor messages, store a concise factual summary rather than copying private correspondence verbatim unless explicitly approved.

## Status vocabulary

- RESEARCHING
- DRAFTED
- READY_TO_SEND
- SENT
- REPLIED_POSITIVE
- REPLIED_NEGATIVE
- FOLLOW_UP_DUE
- CLOSED
