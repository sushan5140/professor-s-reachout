# Professor Reachout

Persistent source of truth for SUSAN's professor outreach.

This repository tracks:
- professor and lab
- university / department
- research fit
- customized outreach draft
- sent / not sent status
- proposal status
- reply status
- next action

## Working rule

Every professor gets a dedicated Markdown file under `professors/<university>/<professor>.md`.

Outgoing email text can be stored in full. Because this repository is public, incoming professor replies should be summarized rather than copied verbatim unless explicitly approved for public storage.

## Status values

- `RESEARCHING`
- `DRAFTED`
- `READY_TO_SEND`
- `SENT`
- `REPLIED_POSITIVE`
- `REPLIED_NEGATIVE`
- `FOLLOW_UP_DUE`
- `CLOSED`

See [TRACKER.md](TRACKER.md) for the current outreach board.
